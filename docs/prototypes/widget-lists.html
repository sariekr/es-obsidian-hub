Try Mail → Unread, a Slack filter, Calendar, or Refresh all widgets.

Find the date once

Today and Yesterday group Mail and Slack. Each row keeps only its time. YouTrack uses State groups instead of implying that every issue has a message date.

Read the useful part first

Sender or issue title leads. Subject or message excerpt follows. Account, channel and priority stay quieter. Slack gets no invented unread indicator.

Keep the familiar structure

Calendar / Mail, YouTrack and Slack stay in place. One refresh action sits in Home; each footer shows its own freshness. The folder sidebar and board remain familiar.

Inspired by Notebook Navigator’s grouped note list and Day Planner’s time alignment. Original HTML/CSS, no plugin code or images copied. This proposal is separate from the implemented 1.4.0 refresh behavior. Installing Notebook Navigator would not restyle Hub’s custom widgets.
